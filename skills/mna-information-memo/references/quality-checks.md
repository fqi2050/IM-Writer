# Quality checks

Check input coverage and unreadable formats. Each material number and claim needs a resolvable source locator; calculated claims also need the arithmetic. Check file hashes if inputs may have changed. Preserve original values and record normalization, including GBP thousands to millions.

Reconcile service/customer totals to the matching P&L period. Calculate customer concentration without counting the aggregate OTHER row as a single customer. Check margins, CAGR year intervals, ownership totals and actual/forecast labels. Missing evidence stays unavailable, not zero.

Inspect HTML at desktop and phone aspect ratios without rearranging content. Check all ten slides if ten are requested, including cover. Test navigation and optional editing/save. Detect element bounds, table wrapping, text overflow and unsupported layout features before conversion.

Verify PPT package slide count, text runs, native table and chart objects, embedded chart workbooks, source speaker notes and absence of full-slide screenshot substitution. Use the presentation finalizer for package, layout and font checks. Visually inspect each rendered slide. A package check and a preview are not evidence of editing inside desktop PowerPoint; state when that test was unavailable.

For the Northbridge fixture, the expected business issues are: revenue 25.0 versus 26.2 million unresolved; GBP 000 sales schedules need conversion; 94% retention lacks a definition/cohort; market size and share unavailable; forecast bridge and QoE/cash/debt/WC evidence missing. Verify a mutation of a source value changes derived output or triggers a reconciliation failure. Verify an HTML edit reaches PPT. Never hardcode the expected pass result.
