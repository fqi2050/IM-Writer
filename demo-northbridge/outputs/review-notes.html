设计及使用限制

本版按三页样张的 KPMG 报告参考风格制作，Arial 替代专用字体。尚未使用正式 PPTX 母版。仓库不包含原始报告、截图、Logo 或专用字体。PPT 文字、14 个表格和 2 个图表均为原生对象，图表附数据快照工作簿。HTML 与 PPT 不会自动双向同步。

本轮 HTML 和原生 PPT 由同一份故事板生成，未通过浏览器读取 HTML DOM。本轮 HTML 未进行浏览器视觉或交互复测。检查程序及已保存结果见仓库 tests 目录；逐页预览和生成工具检查不能代替桌面 PowerPoint 测试。桌面 PowerPoint 的实际编辑、保存和重开尚未实测。

事实及完整来源位于 working/evidence-ledger.json，PPT 备注和 HTML Sources 保留逐条来源位置。早期三页样张保留为风格参考快照，其旧资料状态不代表本版最新证据。
